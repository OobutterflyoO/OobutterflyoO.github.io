# Wahlausschuss Webseite

Statische, responsive Informationsseite fuer den Wahlausschuss.

## Start

Die Seite kann direkt geoeffnet werden: `index.html`.

Fuer die Entwicklung mit Live-Reload kann spaeter Node.js installiert und ein lokaler Server verwendet werden, zum Beispiel `npx serve .`.

## Anpassungen

- Inhalte und Links stehen in `index.html`.
- Gestaltung und responsive Layout stehen in `styles.css`.
- Die mobile Navigation steht in `script.js`.
- Platzhalter wie `wahlausschuss@example.org` muessen vor der Veroeffentlichung ersetzt werden.
